자주 묻는 질문 (FAQ)

외부에서 .md 파일을 불러와 수정했는데 원본 파일이 그대로입니다.

v1.0 의 불러오기 는 외부 파일을 MD Cast 폴더로 복사한 사본을 편집합니다. 원본 위치로 다시 저장하려면 헤더의 더보기(⋯) → 원본 위치에 저장… 메뉴를 사용하세요. v1.1 에서 외부 폴더 직접 편집을 정식 지원할 예정입니다.

iCloud Drive 에 문서가 보이지 않습니다.

기기 설정 → Apple 계정 → iCloud → iCloud Drive 활성화, 그리고 같은 화면에서 MD Cast 토글이 켜져 있는지 확인하세요. 동기화는 네트워크 상태와 파일 크기에 따라 수 초 ~ 수 분이 소요될 수 있습니다.

PDF 의 폰트가 화면과 다르게 보입니다.

시스템 폰트 일부는 PDF 에 임베드되지 않아 fallback 폰트로 렌더링될 수 있습니다. 보다 일관된 결과를 위해 번들 폰트 (Pretendard, Noto Sans KR, Noto Serif KR, D2 Coding, Inter, 나눔고딕, 본고딕) 사용을 권장합니다.

KaTeX 수식이 보이지 않거나 raw 텍스트로 표시됩니다.

인라인 수식은 $...$, 디스플레이 수식은 $$...$$, 여러 줄 환경(aligned, cases 등)은 $$\begin{aligned} ... \end{aligned}$$ 형식으로 작성해주세요. 코드 펜스(```) 안의 수식은 일부러 그대로 표시됩니다.

광고나 데이터 수집은 없나요?

없습니다. 모든 처리는 사용자의 디바이스 내부에서 수행되며, 외부 서버와 통신하지 않습니다. 자세한 내용은 개인정보 처리방침 을 참조하세요.

다른 언어 UI 도 지원되나요?

v1.0 은 한국어 UI 단일 출시입니다. v1.1 에서 영어 / 일본어 UI 를 추가할 예정입니다. (본문에 입력하는 다국어 텍스트 — 한국어/영어/일본어/중국어 — 는 v1.0 부터 자동 폰트 매칭으로 정상 표시됩니다.)

MD Cast

Support · Last updated May 1, 2026

System Requirements

  • iPadOS 17.0 or later
  • iOS 17.0 or later
  • iPad / iPhone only (Mac Catalyst not supported)

Getting Started

  • New document: tap ＋ New in the sidebar.
  • Import file: tap 📂 Import in the sidebar to pick a .md file from the Files app.
  • Switch mode: use the Edit / Read / PDF toggle in the top-right.
  • Adjust formatting: tap the inspector (⚙️) icon — fonts, colors, margins, table styles, paper, and more.
  • Save / load themes: inspector → Theme tab.
  • Share PDF: tap the share (↗) button in the top-right.

Frequently Asked Questions

I imported an external .md file and edited it, but the original file is unchanged.

In v1.0, Import creates a copy of the external file inside the MD Cast folder and edits the copy. To save back to the original location, use the more menu (⋯) in the editor header → Save to Original Location…. Direct editing of external files will be officially supported in v1.1.

My documents are not showing up in iCloud Drive.

In Settings → your Apple Account → iCloud → iCloud Drive, make sure both iCloud Drive and the MD Cast toggle are enabled. Sync time depends on your network and file size — usually a few seconds to a few minutes.

Fonts in the PDF look different from the screen.

Some system fonts cannot be embedded in PDFs and will fall back to substitutes. For consistent results, we recommend the bundled fonts (Pretendard, Noto Sans KR, Noto Serif KR, D2 Coding, Inter, NanumGothic, Source Han Sans KR).

KaTeX math is not rendering, or shows raw text.

Use $...$ for inline math, $$...$$ for display math, and $$\begin{aligned} ... \end{aligned}$$ for multi-line environments such as aligned or cases. Math inside code fences (```) is intentionally left as-is.

Are there ads or analytics?

No. All processing happens locally on your device. The App does not communicate with any external server. See our Privacy Policy for details.

Is the UI available in languages other than Korean?

v1.0 ships with a Korean-only UI. English and Japanese UIs are planned for v1.1. (Multilingual content you write — Korean / English / Japanese / Chinese — is rendered correctly with automatic font matching from v1.0.)

How do I report a bug or request a feature?

Please email us with the following information so we can respond quickly:

  • Device model (e.g., iPad Pro 13" M4)
  • iOS / iPadOS version
  • MD Cast version (Sidebar → About / Licenses)
  • Steps to reproduce — what you did, what you expected, what happened
  • Screenshots or a screen recording, if possible
